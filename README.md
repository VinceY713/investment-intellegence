# 理性仓位管理工具（原型）

一个面向个人投资者的**仓位管理与操作纪律**工具。它不预测涨跌，而是用一套分层量化模型帮你回答四个问题：

1. 单只股票该下多少注（**凯利公式**）
2. 我的分散是真是假（**相关性 / 有效持仓数**）
3. 组合整体风险是否可控（**最大回撤约束**）
4. 这笔操作是否违反纪律（**铁律拦截**）

> 核心理念：投资比拼的是概率认知、仓位管理与人性约束。工具的使命是把"人性约束"固化成代码，在情绪化时刻把用户拉回理性。

## 运行方式

纯静态前端，零依赖，数据仅存本机浏览器（localStorage），不上传。

**方式一：直接打开**

用浏览器打开 `index.html` 即可。

**方式二：本地起个静态服务（推荐，避免个别浏览器的 file:// 限制）**

```bash
# 任选其一
python3 -m http.server 8080
# 或
npx serve .
```

然后访问 http://localhost:8080

## 四层决策架构

| 决策层 | 核心模型 | 拦截的陷阱 | 对应模块 |
|---|---|---|---|
| 单标的下注 | 凯利公式(1/4) + EV 前置 | 单股押注过重 | ① 凯利定注 |
| 组合分散 | 相关性 / 有效持仓数 | 假分散（多只同涨同跌）| ② 组合分散 |
| 总风险控制 | 最大回撤约束 | 组合整体暴露过高 | ③ 回撤控制 |
| 本金防御 | 固定分数止损 + 铁律引擎 | 亏损加仓、追高、无止损 | ④ 止损防御 / ⑤ 铁律校验 |

## 功能模块

- **概览** —— 组合纪律体检（现金池、有效持仓数、回撤预算、因子集中度）+ 因子暴露饼图
- **持仓** —— 录入/编辑持仓（名称、因子标签、占比、浮盈亏、趋势、最大跌幅…），驱动其它模块
- **① 凯利定注** —— EV 前置闸门（EV<0 直接淘汰）→ 满/半/¼ 凯利三档，强制填≥2条正反理由，高胜率警告
- **② 组合分散** ⭐ —— 有效持仓数（逆 HHI，按因子分组）戳破假分散，因子暴露饼图 + 60% 集中度红色警告
- **③ 回撤控制** —— 回撤预算已用/剩余，逐股回撤贡献与理论仓位上限
- **④ 止损防御** —— 固定分数止损反推最大可买仓位
- **⑤ 铁律校验** ⭐ —— 七条铁律，触发即弹出**必须二次确认**的红色阻塞拦截
- **⑥ 加仓/利润** —— 橄榄型仓位模板、正金字塔分批加仓计划、利润隔离提醒与记录
- **设置** —— 全局保守默认值（¼凯利/单股10%/现金池10%/单笔风险2%/隔离30%/回撤15%）+ 数据导入导出

## 模型公式速查

| 模型 | 公式 |
|---|---|
| 期望值 EV | `p×上涨幅度 − q×下跌幅度`（EV<0 直接淘汰）|
| 净赔率 b | `上涨幅度 ÷ 下跌幅度` |
| 凯利公式 | `f = (b×p − q) / b` |
| 半 / ¼ 凯利 | `f×0.5` / `f×0.25`（实战推荐 1/4）|
| 有效持仓数 | 按因子分组后 `1 / Σ(因子权重²)`（逆 HHI）|
| 最大回撤贡献 | `持仓占比 × 该股最大跌幅` |
| 固定分数止损仓位 | `(总资产×单笔风险%) ÷ 止损幅度%` |
