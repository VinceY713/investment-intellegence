# 理性仓位管理工具（原型）

一个面向个人投资者的**仓位管理与操作纪律**工具。它不预测涨跌，而是用一套分层量化模型帮你回答四个问题：

1. 单只股票该下多少注（**凯利公式**）
2. 我的分散是真是假（**相关性 / 有效持仓数**）
3. 组合整体风险是否可控（**最大回撤约束**）
4. 这笔操作是否违反纪律（**铁律拦截**）

> 核心理念：投资比拼的是概率认知、仓位管理与人性约束。工具的使命是把"人性约束"固化成代码，在情绪化时刻把用户拉回理性。

## 运行方式

纯静态前端，零依赖，数据仅存本机浏览器（localStorage），不上传。

**方式一：直接打开**

用浏览器打开 `index.html` 即可。

**方式二：本地起个静态服务（推荐，避免个别浏览器的 file:// 限制）**

```bash
# 任选其一
python3 -m http.server 8080
# 或
npx serve .
```

然后访问 http://localhost:8080

## 四层决策架构

| 决策层 | 核心模型 | 拦截的陷阱 | 对应模块 |
|---|---|---|---|
| 单标的下注 | 股票版凯利(¼) + EV 前置 + 胜率敏感性 | 单股押注过重 / 高估胜率 | ① 凯利定注 |
| 组合分散 | 相关性调整有效持仓数（戳破隐藏集中度）| 假分散（多只同涨同跌）| 股票体检 |
| 总风险控制 | 最大回撤约束（最坏/现实两档）| 组合整体暴露过高 | ③ 回撤控制 |
| 本金防御 | 固定分数止损(分市场) + 铁律引擎 | 亏损加仓、追高、无止损 | ④ 止损防御 / ② 铁律校验 |
| 判断力校准 | 预测-复盘 + Brier 分数 | 长期过度自信 | 复盘校准 |

> 导航顺序（与页面一致）：投资组合 · 资产趋势 · 股票体检 · 持仓 · ① 凯利定注 · ② 铁律校验 · ③ 回撤控制 · ④ 止损防御 · ⑤ 加减仓计划 · 复盘校准 · 使用说明 · 设置

## 功能模块

- **股票体检（概览）** —— 组合纪律体检 +**相关性调整有效持仓数**（戳破隐藏集中度）+ 回撤最坏/现实两档 +**美元敞口(汇率风险)**提示 + 因子暴露饼图
- **持仓** —— 录入/编辑持仓（名称、因子标签、占比、浮盈亏、趋势、最大跌幅…），驱动其它模块
- **① 凯利定注** —— EV 前置闸门（EV<0 直接淘汰）→**股票版凯利**（修正二元全损假设）→ 满/半/¼ 三档 +**胜率−10% 敏感性** + 强制≥2条正反理由 + 一键「记录判断」到复盘校准
- **② 铁律校验** ⭐ —— 七条铁律，触发即弹出**必须二次确认**的红色阻塞拦截；深套加仓对「预先声明的价值分批」放宽为强提醒
- **③ 回撤控制** —— 回撤预算已用/剩余（**最坏(全相关) + 现实(分散调整)两口径**）、逐股回撤贡献与理论仓位上限
- **④ 止损防御** —— 固定分数止损反推最大可买仓位；**A股按涨跌停/T+1/一字板给「跳空最坏情形」更保守仓位**，美股提示跳空/熔断滑价；股数按 100 股/手取整
- **⑤ 加减仓计划** —— 正金字塔分批（含手数取整+交易成本）＋橄榄型模板＋部分止盈；科学退出算法（剔除成本干扰，含 T+1 提醒）
- **复盘校准** ⭐ —— 记录每次判断的胜率/空间，事后回填结果，算出**实际胜率 vs 你以为的胜率 + Brier 分数**，这是长出「投资大脑」的核心闭环
- **设置** —— 全局保守默认值（¼凯利/单股10%/现金池10%/单笔风险2%/隔离30%/回撤15%）+ 数据导入导出

## 模型公式速查

| 模型 | 公式 |
|---|---|
| 期望值 EV | `p×上涨幅度 − q×下跌幅度`（EV<0 直接淘汰）|
| 净赔率 b | `上涨幅度 ÷ 下跌幅度` |
| 股票版凯利 | `f = (p·u − q·d) / (u·d)`（u=上涨、d=下跌，均为小数；修正原二元 `(bp−q)/b` 把下跌当全损）|
| 半 / ¼ 凯利 | `f×0.5` / `f×0.25`（满凯利常 >100%，务必分数凯利+单股上限兜底）|
| 有效持仓数(标签) | 按因子分组后 `1 / Σ(因子权重²)`（逆 HHI）|
| 有效持仓数(相关性) | `1 / (wᵀ ρ w)`，ρ=因子相关矩阵；与标签口径的差 = 隐藏集中度 |
| 组合回撤·最坏 | `Σ 持仓占比 × 该股最大跌幅`（全相关，危机情形）|
| 组合回撤·现实 | `√(ΣΣ wᵢwⱼ ρᵢⱼ ddᵢ ddⱼ)`（分散调整下沿）|
| 固定分数止损仓位 | `(总资产×单笔风险%) ÷ 止损幅度%`；A股再按「至少一个跌停」反推更保守值 |
| 校准 Brier 分数 | `mean((预测胜率 − 结果) ²)`，越低越准（0.25=瞎猜）|

> 相关性矩阵目前为**领域先验**（数据层仅有实时价、无历史序列）。后续接入日K历史即可升级为真实回归相关矩阵。
